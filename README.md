# Praya Service

Praya Service is a background program that provides services to Praya Desktop (https://github.com/BlankOn/praya-gnome-shell-extension).

## Available Services

- Posture Monitoring, heavily inspired by https://github.com/tldev/posturr.
- AI Chat (Experimental), this may be stay experimental until we figured a way to fix visual artifacts while scrolling (Clutter's known issue).
